# F-001 · Increase the number of user by adding…

**Business intent:** Travellers planning a trip get a ready-to-use checklist by picking suggestions from the 'Guides' they already read, so more people start and keep using the app for trip planning. · [intent](../intent/F-001.md) · [design](../design/F-001.md) (Approved)

## Problem
Guides hold useful suggestions (what to prepare, bring, or do), but today a traveller has to retype them into the trip's checklist by hand. That extra work puts people off, and nobody can see whether Guides help people plan, so we can't tell if they bring in or keep users.

## Users
- Traveller / trip owner who builds the trip checklist
- Trip members who tick items on the shared checklist
- Admin who wants to see whether Guides drive adoption

## Done when
A traveller can add a suggestion from a Guide to a trip's checklist in one step and see it on the checklist straight away. Admin can see how many Guide suggestions travellers add to checklists, so the team can tell whether the feature brings in and keeps users. No target is set yet; one will be agreed after a few weeks of real usage data.

## In scope
- Add a suggestion from a Guide to a chosen trip's checklist
- Confirmation when a suggestion is added, and a clear error when it cannot be added
- Counting how often Guide suggestions are added to checklists, visible to Admin
- Accessibility and performance baseline (REQ-025)

## Out of scope
- Native mobile apps
- Payments (phase 2)
- Writing or editing Guide content
- Changing how checklists are shared or ticked by trip members

## Risks
- The need says 'increase the number of user', which is unclear. It may mean more app users, or more travellers on a trip. The Product Owner should confirm before design starts.
- No success metric or baseline exists yet. Pick one metric and set the target only after a few weeks of real data.
- Usage counting must not expose personal data about individual travellers.
- Adoption: travellers may not find the 'add to checklist' action inside Guides.
- Duplicate items if the same suggestion is added twice to one checklist.

## Requirements
- **REQ-002** Accessibility and performance baseline — Approved (Should)
- **REQ-003** Add a Guide suggestion to a trip checklist in one step — Approved (Must)
- **REQ-004** Choose which trip receives the suggestion — Approved (Should)
- **REQ-005** Block duplicate Guide suggestions on one checklist — Approved (Must)
- **REQ-006** Confirmation and clear error when adding a suggestion — Approved (Should)
- **REQ-007** Admin sees how many Guide suggestions are added to checklists — Approved (Must)
- **REQ-008** Admin count by Guide without personal data — Approved (Should)
